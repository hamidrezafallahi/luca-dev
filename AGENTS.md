# Project instructions for frontend work

Before creating or editing frontend UI, read [.docs/frontend-design-system.md](.docs/frontend-design-system.md). It describes the backend theme contract, CSS tokens, typography scaling, component conventions, and review checks. Follow the active theme through every new surface, text style, border, and state. Update that document when the contract or design system changes.

Keep existing user changes intact. The frontend is in `FrontEnd/` and the theme API/domain are in `BackEnd/`.

Before implementing a new feature, read [.docs/feature-implementation.md](.docs/feature-implementation.md) and follow its domain, application, infrastructure, API, admin, migration, and frontend checks.
