# Visual audit - lucaloupe.ir/fa (screenshots in ../screenshots/, named <page>-<viewport>.png)
Pages: home, products, category (ttl-loupes-3), blog. Viewports: desktop, laptop, tablet, mobile. Based on visual inspection only (no DOM measurement; tap sizes estimated).

1. CRITICAL - /fa/products shows "0 items / no product found" (products-desktop.png, products-mobile.png). Fix: verify API response at render time (SSR fetch / caching); if catalog truly empty, add products or noindex.
2. HIGH - /fa/blog shows "no article found" (blog-mobile.png); desktop capture timed out at 30s, laptop OK at 90s (slow). Fix: publish pillar articles, check API.
3. HIGH - Home hero (home-desktop.png, home-mobile.png): value prop is brand-only ("precision in your sight" + English tagline with grammar error "eye deserve"), no mention of dental loupe/Korea/magnification; CTAs are plain underlined text links ("view collection", "special discounts"), no consultation/purchase button. Only consultation CTA is the thin top bar "reserve time". Fix: H1 containing "dental loupe", solid primary button "free consultation / choose loupe", secondary "view prices".
4. MEDIUM - Hero tap targets: two underlined text links ~20-24px tall (home-mobile.png), below 48px; pause button ~40px (OK-ish). Fix: min-height 48px, padding.
5. MEDIUM - Desktop hero (home-desktop.png): decorative "LUCA" watermark and loupe line-art overlap the subtitle and the model list (Classic/Expert/Headband) at right; low-contrast grey labels, text over busy bg. Hero consumes 640px with no product image. Fix: lower watermark opacity, separate layers.
6. MEDIUM - Products section below hero on home appears blank at 1080px (tabs only, carousel arrows) in home-desktop.png - check whether items lazy-load late (CLS/LCP risk). 
7. MEDIUM - CLS 0.045 source: hero buttons container (main.flex > section.relative > div.z-10 > div.flex). Visually the hero swaps from the first-frame layout (mobile: magnification labels x2.5/x3/x3.5 above art; headline wraps to 2 lines "شما" orphan). Fix: reserve fixed min-height for the title/CTA block, use font-display with size-adjust fallback (fonts are self-hosted), fixed aspect-ratio for video/poster.
8. LOW - Hero video (1 MB) not verifiable in a still; mobile screenshot shows dark static frame. Fix: serve poster only on mobile/save-data, preload=none, <=500 KB WebM/H.264 for mobile, pause when reduced-motion (pause button exists - good).
9. LOW - Category page (category-desktop.png, category-mobile.png): products not visible above the fold; "SEO summary" grey box (label literally "خلاصه سئو") shows internal SEO jargon to users and duplicates the intro text; "برو به دسته بندی والد" link missing ZWNJ/spacing style, 30px tall tap target. Image is low-resolution/blurry at 1312px wide. Fix: rename label/remove box, show product grid first, higher-res image with sizes.
10. LOW - Desktop header fine, nav is RTL-correct (Products rightmost). Body text on mobile 16px+ and legible; no horizontal scroll observed. Breadcrumb RTL order correct. Small 11-12px text on desktop (top bar, nav ~13px, "نمایش 0 مورد") - slightly small.
11. INFO - Mobile nav = hamburger right, cart/search left, logo centered: correct for RTL. Mixed Latin digit "0" / "1" in Persian UI vs Persian digits in hero (x۳٫۵) - inconsistent numerals.
